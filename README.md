# Need for Speed: Fuli 2

Браузерная ночная гонка на Three.js. Десять событий карьеры и отдельный заезд с Кайоном проходят на общей сети грунтовых дорог. В обычных заездах игрок управляет направлением движения. В драге Фули сама держит полосу.

## Запуск

Распакуйте архив целиком. В Windows запустите `START_WINDOWS.cmd`. Скрипт использует установленный Node.js или Python 3. Для запуска из терминала откройте каталог с `index.html` и выполните:

```
node server.js
```

Откройте [игру на локальном сервере](http://localhost:8080/). Сервер с Node.js поддерживает диапазонные запросы для видео. Для проверки на телефоне подключитесь к той же сети Wi‑Fi и откройте адрес компьютера с портом 8080. Требуется современный браузер с WebGL 2. Тот же каталог можно разместить на статическом HTTP(S)-хостинге. Three.js, загрузчик модели, шрифты и эффекты включены в поставку.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Газ и тормоз | W и S или ↑ и ↓ |
| Поворот / соседняя полоса в драге | A и D или ← и → |
| Адреналин | Левый Shift |
| Перевести дыхание | E |
| Переключить одну из пяти камер | C |
| Вернуться на дорогу | R |
| Пауза | Esc |

Клавиши, чувствительность и тряска меняются в настройках. На сенсорном экране кнопки принимают несколько касаний одновременно. Для осмотра трассы проведите пальцем по свободному участку экрана. В тюнинге перетаскивание вращает Фули. В свободном беге можно встретить соперников и начать быстрый заезд у стартовой точки.

Адреналин расходуется при ускорении и восстанавливается за обгон, движение по внутренней части трассы на повороте и постепенно во время движения без форсирования.

## Драг

На обратном отсчёте нажимайте и отпускайте газ, чтобы стрелка встретила старт в зелёной зоне. После старта удерживайте газ и перестраивайтесь одиночными нажатиями. Серый сектор означает раннее нажатие, синий даёт хороший перевод дыхания, зелёный — идеальный. В красном секторе нарастает усталость. Всего пять фаз. На последней фазе продолжайте переводить дыхание, чтобы поддерживать скорость. Зелёное окно расширяется при улучшении дыхания. Ветки, камни и лужи стоят на фиксированных местах.

## Музыка и ролики

Положите готовые файлы в эти каталоги рядом с `index.html`. На хостинге важен регистр имён. После загрузки файлов заново откройте страницу.

```text
assets/
  music/
    menu1.mp3  menu2.mp3  menu3.mp3  menu4.mp3
    race1.mp3  race2.mp3  race3.mp3  race4.mp3  race5.mp3
    race6.mp3  race7.mp3  race8.mp3  race9.mp3
  cutscenes/
    cut-scene.mp4
    cut-scene2.mp4
    cut-scene3.mp4
    cut-scene4.mp4
    cut-scene5.mp4
    cut-scene6.mp4
    cut-scene7.mp4
    cut-scene8.mp4
```

Для широкой совместимости используйте MP4 с видео H.264 и звуком AAC. Пустые папки поддерживаются. Музыка начинается после разрешённого браузером взаимодействия. У всех разделов меню общий плейлист. В гонке используется отдельный плейлист. Если доступна только одна композиция, она может повторяться. Во время ролика музыка и игровые эффекты затихают.

| Файл | Момент запуска |
| --- | --- |
| cut-scene.mp4 | Первый вход в карьеру нового профиля |
| cut-scene2.mp4 | Старт третьей карьерной гонки |
| cut-scene3.mp4 | Кнопка «Вернуться в карьеру» после победы в третьей гонке |
| cut-scene4.mp4 | Первый выбор доступной седьмой гонки |
| cut-scene5.mp4 | Принятие предложения Аздата |
| cut-scene6.mp4 | Кнопка возврата в карьеру после победы над Кайоном |
| cut-scene7.mp4 | Старт финальной гонки |
| cut-scene8.mp4 | Победа в финале, перед итоговой статистикой |

Если браузер блокирует автозапуск, на ролике появляется кнопка воспроизведения. Пропуск, естественное окончание и ошибка переходят к нужной сцене игры. Даже при отсутствии файла достигнутый сюжетный эпизод открывается в разделе кат-сцен. После добавления своего видео его можно воспроизвести там.

## Код

Основная логика поставляется в виде исходных ES-модулей. Сборка и установка пакетов для игры не требуются.

| Модуль в src | Содержимое |
| --- | --- |
| main.js, engine.js, career.js | Координация экранов, игровой цикл с физическим шагом 1/60 с, условия открытия и сюжетные переходы |
| world.js, forest.js | Рендеринг, свет, погода, камеры, дорожные покрытия, ориентиры, пространственное разбиение и коллизии |
| actors.js | Исходная модель Фули и анимации Idle/Run, варианты соперников, геометрия Кайона и скутера |
| map.js | Рельеф, узлы, дорожные кривые, составление маршрута и проекция позиции на него |
| race.js, physics.js | Правила гонок, круги, выбывание, позиции, инерция, сцепление, расход адреналина |
| ai.js, drag.js | Траектории, обгоны, препятствия, полосы, старт, фазы и усталость |
| config.js | События, маршруты, награды, погода, параметры соперников, кат-сцены и базовые клавиши |
| tuning.js, economy.js, save.js | Цены, характеристики, покупки, выплаты, рекорды и чтение профиля |
| ui.js, cartography.js, icons.js | Экраны, интерфейс гонок, карта, мини-карта и обозначения |
| input.js, audio.js, video.js | Клавиатура, сенсорный ввод, музыкальные плейлисты, эффекты, воспроизведение видео |
| vendor.js | Локальный Three.js r170, GLTFLoader и клонирование скелета |

Профиль хранится в localStorage под ключом `need-for-speed-fuli-2.v2`, версия структуры 2. Деньги, факт выплаты и решение по Кайону записываются в одном объекте. На другом домене, порту или в другом профиле браузера будет отдельное сохранение.

В графических настройках доступны пресеты и ручная регулировка. Лес разбит на пространственные группы InstancedMesh. Рендерер отсекает невидимые группы, снижает детализацию вдали и использует упрощённую сетку персонажей на низком качестве. Детализация модели хранится в `assets/models/fuli-lod.bin` и использует материалы, вершины и скелет основного GLB.

## Проверка

```
node --test tests/*.test.js
```

Для тестов используйте Node.js 22 или новее. Набор проходит карьеру с автоматическим управлением и покупками, проверяет выплаты, поражения, драг, музыкальные переходы и события видеоплеера. Успешное окончание файла и запрет автозапуска проверяются с управляемым медиаплеером. Качество кодирования и синхронизацию звука ваших файлов следует проверять после их добавления.

## Основа и материалы

Исходная игра — [IamSkoup/nfst](https://github.com/IamSkoup/nfst), ревизия `09aaceefe18f8917fe7684f7a9e74494b07f83cf`. Из неё перенесены GLB Фули, клонирование и проигрывание анимаций, модель скутера с водителем, локальные шрифты и звуковые эффекты. Модель имеет 35 мешей и два исходных клипа анимации. У первой части отдельная архитектура трасс и отдельный ключ профиля.

Three.js распространяется под MIT, шрифты Barlow Condensed и Roboto Condensed — под SIL OFL. Сведения о звуковых эффектах Kenney и тексты лицензий находятся в `assets/` и `assets/fonts/`. Модели персонажей основаны на работе авторов первой части. Названия Need for Speed и The Lion Guard принадлежат их правообладателям.

Источники по механике драга — [руководство по Underground](https://www.gamespot.com/articles/need-for-speed-underground-walkthrough/1100-6085684/), [зоны переключения в Underground 2](https://needforspeedunderground2.org/guides/drag-shifting/) и [сопоставление заездов Underground и Underground 2](https://www.youtube.com/watch?v=hMTurG-tNzo).


### Сквозная проверка в Chrome

Для повторения браузерных тестов запустите сервер на порту 8080. В другом терминале в каталоге проекта выполните:

```
npm install --no-save playwright@1.56.1
npx playwright install chromium
node tests/browser.mjs
```

Можно указать установленный Chrome через переменную окружения `CHROME_PATH`. Тест использует отдельный профиль браузера. Первый прогон ведёт Фули по всем основным маршрутам и трассе Кайона с учётом коллизий карты. Отдельная проверка интерфейса задаёт результаты заездов на границе экранов, чтобы воспроизвести победы, поражения, отказ, повтор, возврат после перезагрузки и точный порядок запросов роликов. Последняя часть переключает ориентацию, отправляет одновременные касания и измеряет частоту отрисовки. На физическом телефоне результат зависит от GPU и браузера.

При открытии игры браузер сразу запрашивает все восемь кат-сцен в фоне и сохраняет полные ролики в кеше. Музыка загружается параллельно отдельной очередью. Для предварительной загрузки нужен HTTPS или localhost. Повторное открытие использует кеш браузера, загружаются только отсутствующие файлы. Полный набор музыки и роликов занимает около 200 МБ. Вступление начинается при первом входе в карьеру. В меню треки идут по порядку от menu1 до menu4, а в гонках от race1 до race9. После последнего трека соответствующая очередь начинается с первого. Начальная громкость музыки — 20 %, пользовательская настройка сохраняется.

В драг-рейсинге музыка отключена. Короткий восходящий сигнал отмечает начало зелёной зоны дыхания. Нажмите клавишу перевода дыхания, пока стрелка находится в этой зоне.

При запуске экран загрузки ждёт модели, музыку, эффекты, шрифты и кат-сцены. Поместите заставку video.mp4 в папку assets/cutscenes рядом с сюжетными роликами. После загрузки она воспроизводится при каждом открытии игры, затем открывается главное меню. Заставку можно пропустить. Если файла пока нет, игра сразу переходит в меню.
